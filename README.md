## Installation

The code requires at least Python 3.10 and the [LayerCake](https://github.com/Climdyn/LayerCake).
To install LayerCake, the simplest way is to use [pip](https://pypi.org/).
In a terminal, run:

```bash
pip install layercake-model
```

and you are set.
In addition, the generated Fortran codes need to be compiled, for example with [GNU Fortran](https://gcc.gnu.org/fortran/).
